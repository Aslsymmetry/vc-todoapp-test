# HARU 공개 공유 앱 재구현

사용자의 최신 요청이 인계 문서의 로그인 요구를 대체한다. 로그인, 계정 생성, 익명 인증, 관리자 계정 접근은 사용하지 않는다. 기존 Firebase Realtime Database 주소와 GitHub main을 유지한다. Vercel 실제 배포는 사용자가 수행한다.

기존 화면 디자인을 유지하며 추가/수정/삭제/완료/검색/필터/중요도/마감일/메모/진행률을 새 코드로 구현한다. Firebase REST를 직접 사용하고 스트림 알림 및 주기 재조회로 여러 브라우저를 동기화한다. 저장 성공은 서버 응답 후에만 표시한다. localStorage는 기본 저장소로 사용하지 않는다.

공유 경로는 sharedTodos이다. 수정은 ETag 조건부 쓰기로 동시 변경을 감지하고 삭제된 항목을 되살리지 않는다. 오류/오프라인/초기 권한 거부는 명확한 상태와 재시도 버튼을 제공한다. 제목과 메모는 텍스트로 렌더링한다.

현재 실제 서버는 인증 없는 읽기에 401을 반환한다. 공개 설정값은 관리 권한을 제공하지 않는다. 코드 재구현은 이 규칙을 우회하지 않으며 실제 공유 CRUD 성공을 주장하지 않는다.
