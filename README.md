# 하루 — 로그인 없는 공개 공유 할 일 앱

HTML/CSS/JavaScript 정적 웹앱입니다. 접속한 누구나 같은 할 일을 보고 추가·수정·완료·삭제할 수 있습니다. 로그인, 회원가입, 익명 인증, 계정 생성은 사용하지 않습니다.

## 기능

할 일 추가/수정/삭제, 완료/미완료, 검색, 진행 중/완료 필터, 중요도, 마감일, 메모, 진행률 및 브라우저 간 실시간 공유를 제공합니다.
기본 데이터베이스는 사용자가 지정한 Firebase 프로젝트 `todo-backend-8ac43`의 Realtime Database입니다. `localStorage`를 기본 DB로 사용하지 않습니다.

## Firebase 경로와 규칙

DB: `https://todo-backend-8ac43-default-rtdb.firebaseio.com/`
공유 경로: `/sharedTodos/{todoId}`.

`database.rules.json`은 공유 할 일 경로만 공개하고 루트 및 다른 경로는 차단합니다. 필수 필드, 타입, 문자열 길이, 중요도, 날짜 형식, 타임스탬프, 생성 시각 변경과 알 수 없는 필드 등을 검증합니다. 관리자 키/비밀번호는 앱에 넣지 않습니다.

규칙 파일을 GitHub에 올리는 것으로 Firebase 서버 규칙이 변경되지는 않습니다. 현재 새 규칙은 소스에만 준비됐으며 서버 적용은 미완료입니다. 기존 이메일/비밀번호 제공자 활성화 설정도 아직 취소되지 않았습니다. 앱 코드는 그 제공자를 사용하지 않습니다.

Firebase 관리자 콘솔 접근은 사용자 요청에 따라 중단했습니다. 서버 규칙을 직접 변경하는 경우 기존 규칙을 백업하고 다른 서비스 경로가 영향을 받지 않는지 검토해야 합니다.

## 공개 앱의 권한

이 목록은 비공개 개인 메모장이 아닙니다. 다른 방문자도 데이터를 읽고 수정·삭제할 수 있습니다. 이는 사용자가 선택한 공개 공유 동작입니다. 민감한 정보를 넣지 마세요.
스키마 검증은 자동 요청 남용, 트래픽/저장 공간 소진 또는 모든 취약점을 막는 보장이 아닙니다. 별도 보안 감사와 App Check/사용량 관리 등의 운영 대책은 수행되지 않았습니다.
이전 브라우저 자료 가져오기는 명시적 확인 후에만 실행되며 공개 목록에 추가됩니다. 브라우저 원본은 삭제하지 않습니다.

## 로컬 실행

Python 3.8 이상에서 `python3 server.py --no-browser`를 실행하고 `http://127.0.0.1:3000/index.html`에 접속하세요. Mac/Windows 실행기도 사용할 수 있습니다. Firebase 접속에는 인터넷이 필요합니다.

## Vercel

`public` 폴더와 `vercel.json`을 사용하는 정적 사이트입니다. Vercel 실제 배포는 수행하지 않았습니다. 관리자 서비스 계정 키는 정적 사이트나 저장소에 넣으면 안 됩니다.

## 검증

- `python3 tests/check_static.py`: 구조 및 설정 검사
- `npm install --no-save playwright` 후 `node tests/browser.cjs`: 계정 없는 모의 브라우저 테스트
- 공유 규칙을 서버에 적용한 뒤 `HARU_LIVE_TEST=1 node tests/live_browser.cjs`: 계정 생성 없이 자기 임시 공유 항목만 만들고 정리하는 실서버 테스트

이번 공개 버전의 실제 Firebase E2E는 아직 미실행입니다. 앞선 로그인 버전의 검증 결과는 이번 버전을 증명하지 않습니다. `VERIFICATION.md`를 확인하세요.
